# Final Project – CI/CD Pipeline

## Project Description
This project demonstrates Continuous Integration and
Continuous Deployment (CI/CD) using GitHub Actions,
Tekton, OpenShift Pipelines, and container deployment.

## Technologies Used
- Python
- Git and GitHub
- GitHub Actions
- flake8
- nose
- Tekton
- OpenShift
- Buildah

## Project Features
- Automated source code checkout
- Python code linting
- Automated unit testing
- Container image building
- Application deployment
- Application log verification

## CI/CD Workflow
1. Cleanup
2. Git Clone
3. Linting
4. Unit Testing
5. Buildah
6. Deployment

## Application Verification
The deployed application should display the
SERVICERUNNING message and listen on port 8000.
